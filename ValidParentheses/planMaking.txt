A string which can only contain the characters '(', ')', '{', '}', '[' and ']', is considered valid. 

=> An input string is valid if:

1. Open brackets must be closed by the same type of brackets.
2. Open brackets must be closed in the correct order.
3. Every close bracket has a corresponding open bracket of the same type.

Important Notes:
- - - - - - - - - - - - - - - - - - - - - - -
=> must be close by same 
=>correct order ( first open, first close)
=> String length must be from 1 to 10^4 (no zero, negative, floating)
=> 3 types of brackets: (), {}, [] 
- - - - - - - - - - - - - - - - - - - - - - -

8. if not same type -> put char of stack1 on stack2 and continue

9. when stack2 is empty but stack1 is not empty -> return false
